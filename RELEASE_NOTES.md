# Galaxy Finder Widget Enhanced v1.3

This release adds extensive customization options to the Samsung Galaxy Finder widget.

If you find this enhanced version useful, [buy me a coffee](https://buymeacoffee.com/xmansyx) ☕

## New Features
- **Customizable widget appearance**:
  - Background color options: dark, light, transparent, or custom color
  - Adjustable background transparency
  - Text color options: dark, light, or custom color
  - Color picker for selecting any custom colors

- **Improved usability**:
  - Taller widget for better visibility (height increased from 44dp to 52dp)
  - Samsung's long-press widget reconfiguration support
  - Real-time preview of customization changes
  
- **Better integration**:
  - Improved theme handling for light/dark mode
  - Support for Android 13+ theme changes
  - Samsung-specific optimizations

## Installation
1. Download the APK from this release
2. Install on your Samsung device
3. Add the widget to your home screen
4. Long-press to customize appearance
